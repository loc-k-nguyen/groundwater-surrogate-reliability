# Code and data availability

The included CSV/JSON summaries reproduce the documented descriptive analyses and figures without raw simulation fields. Fixed split definitions, normalization statistics, and scientific parameter metadata are provided. Simulator launch commands have been removed from the metadata; the remaining fields are unchanged. See `docs/metadata_transformation.json`.

Raw simulation arrays, proprietary simulator setups, executables, checkpoints, and full prediction caches are excluded. Repeating model fitting, inference, and raw-data audits requires separate access to those assets. Portable root options are documented, but raw-data execution was not retested for this repository.

Restricted-asset inquiries may be directed to the corresponding author, Binh P. Nguyen, at binh.p.nguyen@vuw.ac.nz. Access requires approval from the relevant rights holders and is not guaranteed.

This is a private preparation repository. The MIT license covers original project code, not restricted assets. No public archival DOI has been assigned. The manuscript availability statement must be updated only after the chosen public release and archive are verified.
