# Code and Data Availability

This code-only snapshot contains source, frozen splits, scientific parameter metadata without simulator launch commands, and lightweight scalar summaries. Corrected quantitative figures can be regenerated without fields or a GPU.

Raw simulation arrays, simulator setups, executables, weights and full prediction caches are excluded. Repeating fitting, inference and field audits requires those assets and rights-holder approval. Their provision is not promised here. Enquiries may be directed to corresponding author Binh P. Nguyen at binh.p.nguyen@vuw.ac.nz.

Original project code and associated documentation use the MIT license, subject to separately retained third-party notices. The canonical repository is https://github.com/loc-k-nguyen/groundwater-surrogate-reliability; the manuscript-associated snapshot is tag `ems-v6-2026-10-10`. No archival DOI is assigned here. Code availability is not permission to distribute simulator assets, and no journal status is implied.
